Guide · How this page was made

The lab notebook.

Site two of a pair. The studio site argues taste; this one argues proof — so every design decision here optimizes for touching the goods.

Concept

A lab bench: three numbered stations, each a working system you operate — a scripted booking concierge, a live-streaming dashboard with AI narration, and a personal CRM that drafts follow-ups. All logic runs client-side; the fictional “Juniper Dental Studio” supplies the shared narrative.

It is deliberately the studio site’s opposite: light where that is dark, Swiss-tactile where that is cinematic, hard 2px borders and offset shadows where that dissolves into particles.

Design system

Two-color letterpress, extended: warm paper, press-black ink, and an oxblood accent spent on interaction — with ochre and forest as station marks, the palette of a century-old print shop. Hard shadows move when you press; every button physically depresses. Chart colors follow a validated data-viz palette (categorical slots capped at three; single-hue bars for magnitude; status green reserved for “live”).

Typography

Print pedigree over fashion: Besley — a Clarendon revival named for the 1845 Besley foundry — carries the headlines like a scientific catalog. Libre Franklin (Franklin Gothic, 1902) does the body and UI work. IBM Plex Mono handles labels, data, and anything that smells like a machine. All three subset to Latin, embedded base64 — the page makes zero external requests.

The demos, honestly

  • Concierge — a scripted intent-matcher (keywords + a real multi-step booking flow), with typing physics and natural delays. Production versions swap the script for a model grounded in your documents.
  • Pulse — hand-drawn canvas charts on simulated live data: crosshair + tooltip on the line, per-bar hovers, a target reference line, and a narration engine that reacts to what the data does.
  • Orbit — five seeded relationships with warmth scoring, stage advancement, and a typewriter-drafted follow-up per contact, re-thought on every interaction you take.

Engineering notes

  • One self-contained HTML file — no frameworks, no CDNs, no build dependencies at runtime.
  • Charts are raw canvas at devicePixelRatio, redrawn on a 2.5s data tick; tooltips are DOM, not canvas.
  • Hash-canonical router (#/guide) so guide links survive refresh on static hosting.
  • Every animation honors prefers-reduced-motion; the data still ticks, the theatrics stop.
