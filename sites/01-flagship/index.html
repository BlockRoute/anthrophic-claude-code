Guide · How this site was made

An engine room tour.

This page documents the thinking behind the site — the design system, the motion, and the tech — because a portfolio about building things should show its own blueprints.

Concept

The site’s spine is a single hand-rolled WebGL particle engine — no Three.js, no libraries — rendering ~14,000 points that morph between seven forms as you scroll: a torus knot (raw capability), a browser frame, a bar chart, a cube lattice, chat bubbles, a relationship network, and a galaxy disc.

The metaphor is the pitch: the same underlying intelligence, re-shaped for each job a business needs done.

Palette

Cinematic single-theme dark — a deliberate commitment, not a default. The ground is a deep indigo (never pure black), the accent is copper — the metal of wiring, of craft — with periwinkle reserved almost exclusively for the particles.

All three faces are subset to Latin and embedded as base64 — the page makes zero external requests.

Motion system

  • Particle morphs are scroll-driven: each section declares a target form; transitions ease over ~1.2s with per-particle stagger.
  • Display type reveals through line masks; supporting copy follows on a 80–360ms delay ladder.
  • Ambient drift, mouse parallax and depth-attenuated point sizes keep the field alive between morphs.
  • Everything honors prefers-reduced-motion — reveals become instant, the field holds still.

Engineering notes

  • One self-contained HTML file — fonts, styles, and the WebGL engine inlined. No CDNs, no build dependencies at runtime.
  • Custom GLSL vertex/fragment shaders; positions blended on-GPU, buffers swapped CPU-side at section boundaries to avoid pops.
  • Particle count adapts to device (≈14k desktop / ≈7k mobile); DPR capped at 2 for battery sanity.
  • Client-side router serves this /guide view for both path and hash navigation.
